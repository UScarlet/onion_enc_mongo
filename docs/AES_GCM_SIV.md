### 1. Математический аппарат: Конечные поля Галуа

Как и в базовом алгоритме AES, все операции внутри GCM-SIV выполняются не с обычными числами, а с байтами, которые интерпретируются как элементы конечного поля Галуа GF(2^8).

В этом поле определены свои правила арифметики:
**Сложение** выполняется как побитовая операция исключающего ИЛИ (XOR) 
над соответствующими битами двух элементов: R = P xor Q, где r_i = p_i xor q_i.
**Умножение** намного сложнее. Байты представляются в виде полиномов со степенью не выше 7, 
а их перемножение выполняется по модулю специального (неприводимого) многочлена:
m(x) = x^8 + x^4 + x^3 + x + 1

Для алгоритма аутентификации (вычисления хэша) используется расширенное поле GF(2^{128}), где элементами являются уже 128-битные блоки, а умножение идет по модулю другого многочлена: f(x) = x^{128} + x^7 + x^2 + x + 1.


### 2. Этап 1: Функция аутентификации (POLYVAL/GHASH)

Алгоритм должен "прочитать" весь открытый текст (PT) и ассоциированные данные (AAD), 
чтобы сжать их в один математический отпечаток.

В GCM-SIV для этого вычисляется полиномиальный хэш с использованием умножения в поле Галуа GF(2^{128}). 
Процесс выглядит как цепочка умножений и сложений:

1. Берется специальный хэш-ключ H (вычисляется из основного ключа K).
2. Блоки данных (AD, затем PT) последовательно складываются по модулю 2 (XOR) с предыдущим результатом.
3. Результат сложения умножается на ключ H в поле GF(2^{128}).

Этот циклический процесс дает на выходе единый 128-битный блок хэша: GHASH(H, AD, PT).


### 3. Этап 2: Генерация SIV (Synthetic Initialization Vector)

В классических режимах синхропосылка просто генерируется случайно. 
Здесь же он синтезируется математически, чтобы обеспечить детерминированность.

Вычисляется синхропосылка (SIV) по следующей формуле:
SIV = GHASH(H, AD, PT) xor E(K, nonce)
Где:
    H  - хэш-ключ.
    AD - ассоциированные данные (дополнительный контекст).
    PT - открытый текст.
    E  - операция базового блочного шифрования AES.
    K  - ключ шифрования
    nonce - УНИКАЛЬНАЯ синхропосылка

Полученный 128-битный SIV несет в себе информацию обо всем сообщении целиком (выступая как тег аутентификации) и гарантирует, что если на вход поступят одинаковые PT и nonce, то SIV будет абсолютно идентичным.


### 4. Этап 3: Шифрование (Режим счетчика CTR)

Имея стартовую точку в виде SIV, алгоритм переходит к непосредственному шифрованию открытого текста. Открытый текст разбивается на 128-битные блоки P_1, P_2, ..., P_n.

Синтетический IV используется как начальное значение счетчика. Для каждого блока P_i вычисляется соответствующий блок шифртекста C_i по формуле:
C_i = P_i xor E(K, SIV + i)
Где:
    i – номер текущего блока.
    C_i и P_i – блоки шифртекста и открытого текста соответственно.
